# 🛍️ Vijo Shop

O **Vijo Shop** é uma empresa oferecendo projeto de catálogo de produtos afiliados desenvolvido para facilitar a busca por ofertas de diferentes categorias em um único lugar.

Além da divulgação de produtos, o projeto está sendo planejado para evoluir futuramente para uma plataforma de comparação de preços entre marketplaces.

## ✨ Funcionalidades

- 🔎 Pesquisa de produtos
- 📂 Navegação por categorias
- 🛒 Catálogo de produtos afiliados
- 📱 Interface responsiva

## 🚧 Em desenvolvimento

- Busca inteligente (Fuzzy Search)
- Banco de dados de produtos
- Página dinâmica para cada produto
- Filtros por categoria, marca e preço
- Comparador de preços entre marketplaces

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- JSON
- Git & GitHub

## 🎯 Objetivo

Criar uma plataforma rápida, intuitiva e escalável para ajudar usuários a encontrarem produtos e ofertas, servindo como base para um futuro comparador de preços.
